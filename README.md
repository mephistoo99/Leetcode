# LeetCode Solutions

> Personal repository of accepted **LeetCode** solutions, developed, debugged, and memory-tested locally in C. Focused on pointer arithmetic, manual memory management, edge-case resilience, and optimal time/space complexity.

## ⚡ Highlights & Engineering Approach

- **Pure C Execution:** Built from scratch without high-level library abstractions—focusing on raw pointers, array manipulation, and dynamic memory (`malloc`/`free`).
- **Strict Attention:** Zero memory leaks (`valgrind`), edge cases (null checks, integer overflow, boundary conditions), and clean code structure.
- **Local Workflow:** Written, compiled (`gcc -Wall -Wextra -Werror`), and tested locally before submitting to LeetCode.

## Index
- **Language:** C
- **Compiler Flags:** `gcc -Wall -Wextra -Werror`
- **Memory Testing:** `valgrind`
